# Modules · The Complete Git Curriculum

24 chapters, designed to be read in order. Each one ends with the labs, assignments and interview questions that go with it.

## Part 1 · Foundations

| # | Module | You'll learn |
|---|---|---|
| 01 | [Version Control & Git Overview](01-version-control-overview.md) | Why VCS exists, centralized vs distributed, snapshots, the three areas |
| 02 | [Installation & Configuration](02-installation-and-configuration.md) | Config levels, identities, line endings, SSH/HTTPS auth, aliases |
| 03 | [The Core Workflow](03-core-workflow.md) | status, add -p, commit, diff, log, .gitignore, push and pull |

## Part 2 · How Git really works

| # | Module | You'll learn |
|---|---|---|
| 04 | [Git Internals](04-git-internals.md) | Blobs, trees, commits, tags, refs, index, packfiles, reflog |
| 05 | [Undoing Changes](05-undoing-changes.md) | restore, reset modes, revert, amend, reflog recovery |

## Part 3 · Branching and integrating

| # | Module | You'll learn |
|---|---|---|
| 06 | [Branching](06-branching.md) | Branch mechanics, detached HEAD, naming, upstreams |
| 07 | [Merging & Conflicts](07-merging-and-conflicts.md) | Fast-forward, three-way, strategies, conflict resolution |
| 08 | [Rebasing](08-rebasing.md) | Rebase, interactive rebase, autosquash, --onto, golden rule |

## Part 4 · Collaboration

| # | Module | You'll learn |
|---|---|---|
| 09 | [Remotes](09-remotes.md) | fetch/pull/push, tracking branches, refspecs, mirrors |
| 10 | [Collaboration Workflows](10-collaboration-workflows.md) | Feature branch, forks, PRs, protection, CODEOWNERS, merge queues |
| 11 | [Branching Strategies](11-branching-strategies.md) | Git Flow, GitHub Flow, GitLab Flow, trunk-based, how to choose |
| 12 | [Tags & Releases](12-tags-and-releases.md) | Annotated tags, SemVer, automated releases and changelogs |

## Part 5 · Power tools

| 15 | [Rewriting History](15-rewriting-history.md) | filter-repo, BFG, secret purge, repo splitting |
