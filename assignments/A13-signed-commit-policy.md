# A13 · Signed Commit Policy

**Level:** Intermediate · **Estimated time:** 1.5 hours · **Related:** [Module 19](../modules/README.md)

## Objective

Roll out commit signing for a team.

## Requirements

1. Configure SSH signing for yourself and verify locally with an allowed-signers file.
2. Enable 'require signed commits' on main.
3. Write a one-page onboarding guide covering macOS, Linux and Windows, plus troubleshooting.
4. Show what happens when an unsigned commit is pushed to a PR.

## Deliverables

- SIGNING.md
- Screenshots/outputs of verified and rejected commits

## Grading rubric

| Criterion | Points |
|---|---|
| Working setup | 35 |
| Guide quality | 40 |
| Policy enforcement | 25 |
| **Total** | **100** |

## Stretch goal

Try keyless signing with Sigstore gitsign.
