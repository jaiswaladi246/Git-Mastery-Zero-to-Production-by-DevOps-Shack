# A20 · Capstone: Repository Governance

**Level:** Staff-level · **Estimated time:** 1 day · **Related:** [Module 24](../modules/README.md)

## Objective

Design and implement Git governance for a fictional 200-engineer company, 'DevOps Shack Cloud'.

## Requirements

1. Write a Git standards document: branching strategy, commit conventions, PR rules, release process.
2. Create a service template repo (README, CONTRIBUTING, CODEOWNERS, SECURITY, pre-commit, CI, PR template).
3. Manage two repos and their protections with Terraform (GitHub or GitLab provider).
4. Set up backups (mirror job), audit-log export plan and a quarterly access review process.
5. Define and show how you'd compute DORA lead time from Git and deploy data.

## Deliverables

- Standards doc
- Template repo
- Terraform code
- GOVERNANCE.md tying it together

## Grading rubric

| Criterion | Points |
