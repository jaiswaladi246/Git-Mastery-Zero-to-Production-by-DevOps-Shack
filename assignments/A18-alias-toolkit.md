# A18 · Your Git Alias Toolkit

**Level:** Beginner · **Estimated time:** 1 hour · **Related:** [Module 23](../modules/README.md)

## Objective

Build a personal Git toolkit you'll actually use daily.

## Requirements

1. At least 12 aliases covering status, graph log, undo, amend, cleanup of merged branches, recent branches and fixup+autosquash.
2. Conditional includes for work vs personal identity.
3. URL rewriting so HTTPS GitHub URLs use SSH.
4. Keep it in a dotfiles repo with an install script.

## Deliverables

- Dotfiles repo link
- TOOLKIT.md explaining each alias

## Grading rubric

| Criterion | Points |
|---|---|
| Usefulness | 40 |
| Correctness | 30 |
| Docs | 30 |
| **Total** | **100** |

## Stretch goal

Add shell completion and a `git-<name>` custom command script on your PATH.

Put everything in a public repository named `git-mastery-a18-alias-toolkit` and share it on LinkedIn with **#DevOpsShack** and **#GitMastery**. A recruiter-visible Git portfolio is worth more than a certificate line on its own.
