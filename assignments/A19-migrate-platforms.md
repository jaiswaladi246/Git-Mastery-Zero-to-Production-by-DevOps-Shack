# A19 · Migrate Between Platforms

**Level:** Advanced · **Estimated time:** 3 hours · **Related:** [Module 22](../modules/README.md)

## Objective

Migrate a repository with full history from one platform to another.

## Requirements

1. Mirror a repo (all branches and tags) from GitHub to GitLab (or vice versa) with `--mirror`.
2. Import issues and PRs/MRs with the platform importer.
3. Convert one CI pipeline (Actions ↔ GitLab CI).
4. Recreate protections and CODEOWNERS; set up ongoing mirroring during the transition.

## Deliverables

- Both repo links
- MIGRATION.md with checklist, issues found and rollback plan

## Grading rubric

| Criterion | Points |
|---|---|
| Full Git data migrated | 30 |
| Metadata imported | 20 |
| CI converted | 25 |
| Plan quality | 25 |
| **Total** | **100** |

## Stretch goal

Automate the migration for N repos with a script using platform APIs.

## Submission tip

Put everything in a public repository named `git-mastery-a19-migrate-platforms` and share it on LinkedIn with **#DevOpsShack** and **#GitMastery**. A recruiter-visible Git portfolio is worth more than a certificate line on its own.
